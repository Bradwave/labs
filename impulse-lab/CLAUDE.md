# Impulse Lab

Follow `../DESIGN.md`: it is the design standard of all the labs (header, settings menu, components, Italian and English, plots, PWA, repository layout). This file only adds what is specific to Impulse Lab.

- Impulse, momentum and collisions: J = ∫F dt = Δp. Four scenes: impact on a force sensor, draw F(t), a rain of impulses, the ballistic pendulum.
- Run locally: `python3 -m http.server 8100` in the repository root, then open http://localhost:8100/impulse-lab/ (the `labs` entry in the root `.claude/launch.json`).
- The shared kit is `../kit/` (loaded from the page, never copied here). `sw.js` and `manifest.webmanifest` are generated by `node ../tools/sync-kit.mjs impulse-lab` (run from anywhere): never edit them by hand.
- Before a release: sync, `node ../tools/check-app.mjs impulse-lab`, `node --test tests/`, then bump `VERSION` in `js/boot.js` and `package.json`.

## Code layout (an exception to DESIGN.md §16)
- `js/boot.js` is an ES module: it starts the kit and sets `window.KIT`.
- `js/01-core.js` … `js/06-app.js` are **classic scripts** sharing one global scope, loaded with `defer` right after `boot.js`, in file order. Helpers must be defined in an earlier file than their users. This was a single concatenated build before (2026-11-09); turning it into real ES modules is possible later but not required.
- Strings: `js/strings.js` (same keys in `it` and `en`, `help.body` is HTML). In the scripts use `T('key', a, b)` (fills `{0}`, `{1}`); markup uses `data-i18n`. On a language change the kit runs `applyLang()` in `06-app.js`, which relabels everything generated in JS (`relabel()` of each scene).
- Physics colours come from the kit (`--force`, `--mom`, `--vel`); Impulse-only colours (`--imp` for J, `--q` for the collision phase, `--c1…--c3` for pinned curves) live in `css/app.css`.
- Share link and copy image are settings-menu items (registered in `boot.js`, implemented in `06-app.js` as `window.IMPULSE`).
