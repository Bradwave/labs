# Dynagraph XR

Dynagraphs in augmented reality: a function is drawn between parallel axes, a number on the top axis is joined by a line to its value below. Move the inputs of f and g with your hands, add a third axis for the composition h(f(x)), leave a trace, draw samples, or put the cartesian graphs beside the axes. Quest Browser and desktop (orbit camera). The AR version of the Dynagraph web app; see `docs/PLAN.md`.
