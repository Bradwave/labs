# Pendulum Lab

Follow `../DESIGN.md`: it is the design standard of all the labs (header, settings menu, components, Italian and English, plots, PWA, repository layout). This file only adds what is specific to Pendulum Lab.

- Pendulum simulator for physics teaching: forces and the third law, energy, graphs, the ball's non-inertial frame, liquid in the ball, coupled and driven pendulums.
- Run locally: `python3 -m http.server 8100` in the repository root, then open http://localhost:8100/pendulum-lab/ (the `labs` entry in the root `.claude/launch.json`).
- The shared kit is `../kit/` (loaded from the page, never copied here). `sw.js` and `manifest.webmanifest` are generated by `node ../tools/sync-kit.mjs pendulum-lab` (run from anywhere): never edit them by hand.
- Before a release: sync, then `node ../tools/check-app.mjs pendulum-lab`, then bump `VERSION` in `js/main.js`.
- Strings: `js/strings.js` (same keys in `it` and `en`); generated lists (show switches, quick chips, graph chips) are rebuilt by `relabel()` in `js/ui.js` when the language changes.
- Code style: dense one-statement-per-line modules from before the kit; new code may follow Prettier style (DESIGN.md §16).

## Model notes
- Integration: fixed small steps (≤ 0.5 ms, smaller when the support is driven fast), rendering at display rate (`js/main.js`).
- Physics colours: weight uses `--pos` (blue), tension `--force` (red), velocity `--vel`, acceleration `--acc`; pendulum-only colours (`--drag`, `--app`, `--liquid`, `--ball2`, `--spr`) live in `css/app.css`.
