# Series Lab

Follow `../DESIGN.md`: it is the design standard of all the labs (header, settings menu, components, Italian and English, plots, PWA, repository layout). This file only adds what is specific to Series Lab.

- What it is: Partial sums of a complex series in the Argand plane: write the general term and watch the polygonal path converge (or not).
- Run locally: `python3 -m http.server 8100` in the repository root, then open http://localhost:8100/series-lab/ (the page loads the shared `../kit`).
- The shared kit is `../kit/`. `sw.js` and `manifest.webmanifest` are generated by `node ../tools/sync-kit.mjs series-lab`: never edit them by hand.
- Before a release: `node ../tools/sync-kit.mjs series-lab` then `node ../tools/check-app.mjs series-lab`.
- Strings: `js/strings.js`, same keys in `it` and `en`. Interface default is Italian.
- Tests: `node --test tests/`.

## Notes
<!-- physics model, decisions, open questions -->
- Pure modules (no DOM, tested): `js/expr.js` (recursive-descent parser compiled to closures, complex numbers as `[re, im]`, variables `n` and `z`) and `js/series.js` (partial sums stop at the first non-finite term; `limitEstimate` hides the Aitken estimate unless it is stable and the terms shrink).
- Palette: cyan background with a burnt-orange accent, chosen to stay clear of the other labs' hues (`node tools/check-palettes.mjs`).
- PNG icons were rendered with Playwright from `favicon.svg` (`tools/make-icons.mjs` needs macOS `sips`).
- Ideas not done: more input syntax (`sum`, piecewise terms), complex-valued `n`, convergence tests (ratio, root) shown as text, share view/zoom in the link.
- Field view: `js/field.js` keeps running sums per cell and adds one term to every cell per step, within a time budget per frame; the last complete image (`fieldShown`) stays on screen while a new grid (pan, zoom, resolution, expression) is recomputed, and is drawn through the current window, so panning never flashes. The cursor runs to `nMax − n0` even when the series at the selected z stops earlier.
